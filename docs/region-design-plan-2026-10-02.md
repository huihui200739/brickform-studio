# 连续表面与材质设计：当前根因及下一工作包

## 结论

当前模型能生成文件、保留雕像和火盆、通过若干连接检查，但仍没有达到可以按套装交付的质量。需要把“预测网格”转成“积木设计目标”，再选择零件。现有排砖器无法自行判断某个起伏是墙饰还是重建噪声、某个暗色是材料还是阴影。

本次审查覆盖生成主链：本机单图/三图重建、GLB 读取、相机/配色、实例与组件、几何整理、体积与排砖、连接和采购、步骤及导出。没有将普通 UI 组件库逐行审阅算作生成算法审查。历史审查和已经完成的修复见 [总审查](product-quality-audit-2026-09-30.md) 与 [实施进度](product-quality-implementation.md)。本文针对 `2652142` 的剩余缺口；不是新的完成声明。

## 1. 雕像周围的杂色来自什么

后墙声明区域已经是连续沙色墙面，但旁边的门框、侧面和门楣仍从照片辐射颜色获得棕色。它们不全是“未看到的背面猜色”。已有源面积审计在门框区域找到 94 个普通零件：55 沙色、25 深棕、14 棕色；暗色对应面积中约 80.9% 有可见图片样本。**有可见样本不等于已经识别真实材质，也不等于内部像素对应正确。**

两条简单改法已经做过反证：

- 提高可见样本优先级：火焰的橙色像素可能投到墙上，会把正常墙砖染成橙色。
- 用相邻亮墙给暗墙提亮：只处理同色度的标量阴影，神庙最深的棕色区域没有相容的亮沙色见证；真实深沙色涂装与同色度阴影可以有完全相同的像素。

当前诊断原型只把 23 件深沙色改为沙色，主要棕色条带仍存在。一个特意构造的真实深沙色渐变涂装反例被错误提亮，因此该原型**没有接入生产**。普通深色木材、蓝墙或深色涂装反例通过，不能抵消这个失败。

## 3. 下一工作包的具体边界

### A. 保留观测，单图和三图共用下游

新增 `SceneSurfaceGraph`：源三角面 ID、原尺寸/变换、真实共边邻接、法线、洞与边界、可见像素坐标和原始 RGB、图像 ID、相机、观测覆盖及来源。三图保留各视图 K/R/t、有效深度和置信度，不以平均颜色代替所有观测。单图没有获得的深度/背面证据保持缺失。

原始照片、观测 RGB 与网格保持不可变。另存几何候选、材料候选、假设来源及拒绝理由，方便回滚和审计。`observed` 不再被理解成“该积木颜色已知”。仅新增类型/警告不算完成本工作包。

### B. 独立估计材料与光照

以连续物理表面为单位估计材料；原图的亮度变化由独立光照解释。可使用本机学习模型产生反照率候选，但它仍是估计，不能伪装成真实零件颜色。

优先验证 [Marigold IID Lighting](https://huggingface.co/prs-eth/marigold-iid-lighting-v1-1)：官方模型同时估计反照率、彩色漫反射光照和非漫反射残差，能提出当前标量提亮规则缺少的彩色光照解释。使用固定 revision、核验文件哈希、原图留在本机；代码及模型分别遵循其 [官方许可](https://github.com/prs-eth/Marigold#-license)。这不是已经接入或已证明改善的功能。[另一候选 Intrinsic](https://github.com/compphoto/Intrinsic#license) 的实现限定学术用途，不作为本产品默认依赖。

同模型多次预测一致，只说明预测稳定，不能证明材料正确。必须检查真实蓝屋顶/棕木/黑灰白装饰保留，火焰和树的原始 mask 不污染墙面，原图内的色界与位置对应不退化；不能以颜色种类更少判定成功。

本次进行了有时间上限的本机评估准备：固定官方 revision 与哈希，建立隔离运行环境；网络传输未能在上限内取得并核验完整权重，已停止下载。**没有执行材质模型推理，没有 albedo 改善或速度成绩，没有接入生成流程。** 记录在 `benchmarks/intrinsic-material-evaluation-2026-10-02.json`，不把模型论文中的能力当成本项目的实测结果。

### C. 提出完整表面候选，再排砖

首批支持有观测支持的连续平面和倾斜面：墙、平台、屋顶和车身大面。按真实共边、开口/折角、图像边界及残差提出整片候选，保留窗洞、台阶、装饰和轮廓；不用场景名字授权固定模板。曲面及不确定区域继续保留草稿，不强行套平面。

每个候选用同一来源相机重新投影，检查轮廓、开口、明确装饰以及几何残差；辐射差异通过明确的光照模型解释。只在几何与材料解释共同改善、关键结构未退化时采用。连接失败撤销候选，不能通过向可见空隙补柱掩盖错误形状。

随后按连续区域共同选择墙砖、错缝、铺面、斜坡件和内部跨梁；保留既有目录碰撞、组件安装、连接与采购约束。它是设计阶段，不是提高体素分辨率。

## 4. 验收及额度控制

先在两个真实失败源图和少量明确反例上做小候选与固定 CAD 对比；没有可见改善或破坏真实配色就拒绝，避免立即重跑整套转换。生产方案冻结后才执行一次当前六类样例及两份神庙三档的完整回放，复用绑定输入/模型指纹的缓存；只针对具体风险追加测试。

本工作包至少需要：

1. 神庙门框/侧墙杂色有可解释且可复查的改善，雕像和两只已连接火盆保留。
2. 小屋完整屋顶/墙面同时改善，蓝屋顶、棕木和灰白装饰保持；不能只改善神庙。
3. 已知相机的噪声平面、倾斜面、窗洞、真实深色装饰、阴影五类控制通过；含“像素相同而材质解释不同”的不确定例，不能给无证据的成功判定。
4. 最终 CAD 四视角、原图对应、碰撞/连接/实际安装顺序、BOM 与采购来源共同检查。指标通过但肉眼仍有错块时，外观验收失败。

六张当前跨类别样例是公开引擎样例渲染，不是独立真实照片；它们全部仍按草稿处理。后续还需独立照片评估、完整装入路径、子装配图示和真人完整试拼。照片中的背面、内部和被遮挡连接仍不能从单张图唯一确定；产品应提供有依据、可校正的积木设计，而不是把猜测包装成原套装的精确零件复刻。
