# Brickform 积木工坊 · V3

本机运行的图片参考与积木设计工作台。V3 新增小鸭部件设计，保留 V2 的图片轮廓立体 / 浮雕。图片不上传服务器；没有接入 AI 识别或三维重建，刷新会清空本次设计。

## 运行

Node.js 22.13+（推荐 24）。

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

## 两条独立生成路径

### 小鸭部件设计（默认）

- 用户明确选择小鸭结构，不能识别任意物体。参考图仅提取主要配色、红橙色嘴部候选，以及两档头身 / 身体比例；也可以完全手动设定。
- 用基础砖、薄板、弧面斜坡、45° 斜坡、光面板、侧凸点砖和圆形光面板组成六个部件：身体、翅膀、尾巴、头部、嘴、眼睛。
- 四组比例组合约 128–175 块（以实际生成值为准），不自动增加底座或支撑柱。
- 每个零件保留 LDraw 的平移、完整旋转矩阵、部件和步骤编号。侧装眼睛与翅膀使用真实侧凸点位置。
- `model.levels` 在此路径表示步骤索引，`brick.step` 是所属步骤；不能用安装高度替代搭建次序。
- 实时 3D 从自带的 LDraw 网格加载，不在用户会话中请求第三方零件资源。支持五个视角、部件单独查看、分部件展开与逐步搭建。
- 检查保守外包框碰撞（排除曲面件背面合法凹槽）、顶部 / 侧面凸点与底部连接位置、安装次序、完整连接图。不是受力模拟或实物拼装证明。

### 图片轮廓模式

1. 图片缩放到最长边 128 像素，透明图片参考 alpha，从边界泛洪去除近似背景。
2. 映射到 20 / 28 / 36 凸点规模，以 8 mm 凸点间距、3.2 mm 薄板高度修正纵向比例。
3. 立体模式按轮廓距离估算厚度，浮雕模式使用均匀厚度。合并为 10 种基础砖和薄板。
4. 加入两层交错底座和必要的同色支撑；检查网格碰撞、下方承托与整体连通。
5. 该路径仍使用实例化砖体与凸点近似渲染，不具有真实背面重建能力。

## 零件与导出

- 工作台、CSV、LDraw、HTML 说明书均由同一份已生成模型驱动。未应用的参数不会进入导出文件。
- LDraw 保留官方库编号、颜色、位置、方向及 STEP。库编号的 b 等后缀是形态版本，不等同于 LEGO 商店的设计编号。
- 小鸭说明书使用等轴测外形简图，省略空腔，标出本步新增零件、坐标、底部高度、安装方向。轮廓模式使用编号俯视图。
- HTML 可离线打开、打印或另存为 PDF。CSV 带 UTF-8 BOM。
- 没有完整的零件 / 颜色组合白名单、实时库存或价格。具体编号和配色必须在购买前核对，不保证仍在生产或在售。

真实几何来自 [LDraw.org Official Parts Library](https://library.ldraw.org/)，这是社区维护的零件库，与 LEGO Group 无关联。原始文件及作者信息保留在 `vendor/ldraw`；公开署名与授权在 `public/parts/ATTRIBUTION.txt`，使用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。网格由 Three.js LDrawLoader 解析并三角化。

更新受限零件库时运行 `node scripts/prepare-parts.mjs`，只从 LDraw 官方库下载缺少的文件，再生成 `public/parts/geometry.json` 与署名文件。日常构建不需联网下载零件。

## 代码入口

- `app/page.tsx`：工作台、图片读取、参数与导出。
- `lib/duck-designer.ts`：参考图配色 / 比例、小鸭部件语法与搭建顺序。
- `lib/assembly-catalog.ts`：零件尺寸、原点、矩阵工具。
- `lib/assembly-validation.ts`：顶部及侧面连接、外包框检查。
- `components/assembly-viewer.tsx`：真实网格预览、视角、展开与部件查看。
- `lib/assembly-diagram.ts`：离线说明书简图及方向文字。
- `lib/brick-engine.ts`、`components/model-viewer.tsx`：保留的轮廓生成与显示。
- `lib/manual.ts`：两种模式的说明书、CSV 与下载。

## 验证与限制

13 项测试覆盖原有轮廓模式、四组小鸭比例、实际参考图配色变化、侧向连接、错误连接 / 顺序 / 碰撞的拒绝，以及模型、LDraw、说明书和 CSV 的一致性。每个部件都有有限、完整的内置网格及来源信息。

`scripts/render-assembly.py` 可在本地从同一份网格独立渲染模型，辅助检查几何外观；这不是浏览器 UI 测试。本轮未做浏览器截图或交互测试。物理稳定性、夹持力、抗倾倒与实物拼装仍未验证。

使用 Sites / Vinext，部署归属在 `.openai/hosting.json`；构建产物位于 `dist/`。
