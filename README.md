# Brickform 积木工坊 · V2

图片轮廓转积木摆件的第二版。图片在用户浏览器中处理，不上传服务器。没有 AI 三维重建或远端推理服务，刷新会清空本次设计。

## 运行

需要 Node.js 22.13+（推荐 24）。

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

## 功能与数据流

1. PNG / JPEG / WebP 上传（10 MB 上限），最长边缩放到 128 像素进行分析。
2. 从图片边界泛洪去除近似背景，透明 PNG 参考 alpha；保留主体内封闭的白色细节。
3. 将主体缩放到 20 / 28 / 36 凸点的最长边，按凸点间距 8 mm、薄板高 3.2 mm 修正竖向像素。映射到 6 色基础色板。
4. 默认圆润立体模式根据轮廓距离场估算变化的厚度，浮雕模式保留等厚拉伸。加入两层交错薄板底座；按整个零件的下方连接检查，只在必要位置补入主体主色的支撑列，优先选择中央及较短支撑。
5. 在 3.2 mm 体素网格上合并成 10 种砖块/薄板，优先选择有下方接触和体积较大的零件。每块拥有唯一序号、坐标、宽深高、颜色和设计编号。model.levels 记录有新增零件的安装基准高度。
6. 检查体素重叠、下方承托、砖块连接图整体连通。底座第一层需要先摆放，再由第二层连接。
7. 同一份模型驱动 Three.js 预览、分层图纸、零件清单、LDraw 与 HTML 说明书导出。离线 HTML 自带打印按钮，可在浏览器存成 PDF；CSV 带 UTF-8 BOM。

内置小黄鸭为独立参数化示例，不是图片识别结果。3D 渲染使用实例化砖体及凸点几何，表现零件外形，未绘制底部空腔与管柱。

## 零件与来源

砖块设计编号：3005、3004、3010、3003、3001；对应薄板：3024、3023、3710、3022、3020。参照 [LEGO Pick a Brick](https://www.lego.com/en-us/pick-and-build/pick-a-brick)；色板保留 LEGO 颜色编号和 LDraw 颜色编号两个字段。颜色显示为近似屏幕色。

尚未接入完整零件数据库、零件与颜色组合白名单、实时库存或价格。生成的具体零件/颜色组合需要在备料前核对，不能以本原型作为官方生产或库存保证。

## 边界

- 图片背面与深度是推测，距离场圆润厚度仍不能还原任意物体的真实三维形状。
- 网格检查不等于物理稳定性、抗倾倒、连接强度仿真或实物试拼。
- 自动支撑可能改变外观，清单和说明书包含支撑，不应擅自移除。
- 没有账号、历史项目存储、完整官方零件库或采购功能。
- 工具与 LEGO Group 无关联或认证。

## 代码入口

- `app/page.tsx`：工作台、图片解码、参数与导出交互。
- `components/model-viewer.tsx`：Three.js 预览和资源生命周期。
- `lib/brick-engine.ts`：图片轮廓、积木布局、结构检查、清单、LDraw。
- `lib/manual.ts`：分层矢量图、CSV、可打印 HTML 说明书。
- `lib/brick-engine.test.ts`：多尺寸连通性、碰撞、图像边界与导出检查。

使用 Sites / Vinext 构建，部署归属记录在 `.openai/hosting.json`。构建输出位于 `dist/`。

## V2 界面与验证

修复全局焦点选择器误给所有按钮/链接描边的问题。工具栏具有明确间距，标题截断并支持改名，成功提示 5 秒后消失。3D 视角在分步切换时保留，重置与展开会按视口比例自动框选模型。

测试包含实际生成小黄鸭图片的 128px RGBA 固定样本，两种生成模式、3 档精细度、宽窄图片、透明图片及多种深度。检查每种零件尺寸、体素碰撞、下方连接、整体连通、LDraw 高度以及说明书/CSV 完整性。源码中的焦点样式经过选择器检查；本轮未做浏览器截图或交互测试。
